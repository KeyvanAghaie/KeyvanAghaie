## About me

My work connects **Python-powered AI** with **reliable backend architecture** and **responsive frontend experiences**. Over the past decade, I've worked across enterprise AI, financial platforms, banking, and cloud infrastructure, with remote teams in Australia, Canada, and the UAE.

At **Code Clan**, I build RAG pipelines, optimize LLM agent workflows, and develop real-time dashboards. I care about practical engineering: faster answers, lower latency, and systems that keep working as usage grows.

## A few things I've built

- **Enterprise knowledge search:** processed 80,000+ vector embeddings and reduced document search time from 20 minutes to under 4 seconds.
- **More efficient AI workflows:** reduced LLM token costs by 35% through semantic caching and better chunking strategies.
- **Distributed financial systems:** supported 150 transactions per second and brought API read latency down from 5 seconds to 500 ms.
- **Platforms at scale:** helped grow an AWS-hosted platform from 7,300 to 255,000+ active users.
